## Normal-state prompt

Generate ONE production-ready 2D game UI button background asset for a horror game's old damp basement title menu. No text, no letters, no symbols, no icons. A VERY WIDE horizontal rectangle, canvas aspect about 5:1, designed to be displayed at 330 by 64 pixels. The rectangular button nearly fills the canvas with only a tiny transparent outer margin. Perfectly front-facing flat orthographic UI element, straight edges, nearly square subtly chipped corners. Surface is aged dark charcoal plaster and porous rough stone, faint worn brick-like mineral texture, damp desaturated deep green-gray undertones, understated pale warm dusty edge, distressed old cellar material. Matte, subdued, quietly eerie, NOT metallic: no metal, no rivets, no screws, no chrome, no polished bevel, no shiny reflections, no mechanical decoration. Mostly very dark and uniform calm center so white Korean text can be overlaid by the game. A thin irregular worn stone outline rather than a large ornamental frame. Clean silhouette and simple proportions. Actual transparent background outside the rectangle, no surrounding environment, no drop shadow, no mockup, no lettering. Make the image itself extremely wide, not a small button in a square canvas.

## Hover-state prompt

Reference/edit target: generated normal-state PNG.

Edit this exact game UI button image to make its mouse-hover state. Preserve the exact canvas size, position, silhouette, transparent margins, chipped shape, perspective, and all stone/plaster crack details. Change only lighting: subtly brighten the old matte plaster surface and the thin dusty rim as if a very soft warm flashlight light touches it. Dark gray-green damp cellar stone and aged plaster. Keep the broad center dark enough for white game button text. Very subtle warm parchment light on the rim, not a neon glow. No text, no symbols. No metal, no polished finish, no glossy bevel. Preserve actual alpha transparency outside the existing shape. This is a matching hover-state texture, not a new composition.
